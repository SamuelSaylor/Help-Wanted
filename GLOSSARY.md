# Help Wanted

A tool that helps a person who has never contributed to open source find a project and an issue that suit them.

## Language

### People

**Contributor**:
The person who uses the tool to find something to work on. Usually a beginner.
_Avoid_: User, human, developer

### What we know about the Contributor

**Contributor Profile**:
The Contributor's own answers to the questionnaire: what they want to work on, the languages they code in and speak, how much time they have, what they say about their experience, and how many Recommendations they want.
_Avoid_: User profile, context profile, preferences, master profile

**Skill Assessment**:
What the Contributor can already do, judged from what they say about their experience and from their public GitHub activity.
_Avoid_: Technical abilities, skills file, contributions file

### What we find

**Candidate Project**:
An open-source repository that matches the Contributor Profile and Skill Assessment and is worth searching for issues.
_Avoid_: Potential project, repo match

**Recommendation**:
One issue suggested to the Contributor, with why it fits them, what they will learn, and their first steps.
_Avoid_: Result, match, suggestion
